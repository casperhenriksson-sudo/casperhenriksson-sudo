I offer a focused JavaScript, TypeScript or Python bug fix from **USD 5**, using an existing free test setup. The starting package covers one agreed bug in a module of up to 300 lines.

Delivery includes the patch, a regression test shown failing before the fix and passing afterward, and the exact verification commands and observed results. Scope, feasibility and timing are confirmed before accepting an order. AI assistance and verification limits are disclosed.

## MakerPrice: price a batch of handmade products

MakerPrice is an offline browser calculator for candle, soap, jewelry and other handmade-product batches. Import costs from its CSV template, compare products, explore fee and discount assumptions, and export CSV or values-only XLSX results.

It assumes one item per order. Enter platform fees yourself; automatic VAT or income-tax calculations and live marketplace integration are not included.
